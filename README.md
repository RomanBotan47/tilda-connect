## Для пользователей

1. Скачайте готовый пакет для своего компьютера. Название пакета указывает систему: mac-arm64 — Mac с Apple Silicon; mac-intel — Mac с Intel; windows-x64 — Windows x64; windows-arm64 — Windows ARM. Публикуются только собранные варианты. Все необходимые компоненты уже внутри.
2. Распакуйте архив. На Mac откройте **Tilda Connect.app**. На Windows нажмите **«Извлечь всё»**, затем в папке Tilda Connect запустите **«Подключить Tilda.cmd»**.
3. В открывшемся окне выберите **Codex**, **Claude** или **Claude Code**.
4. Вставьте ключ Tilda в скрытое поле и нажмите **«Подключить Tilda»**.
5. Дождитесь подтверждения, полностью закройте выбранное приложение и откройте его снова. Начните новый чат.

Ключ создаётся в **Tilda → Профиль → MCP-сервер → Новый ключ**. Выберите свой проект, разрешённые действия и срок. Подключение доступно на тарифах Personal и Business. Ключ показывают один раз. [Инструкция Tilda с картинками](https://help-ru.tilda.cc/mcp).

Мастер сам проверяет ключ, сохраняет его в защищённом хранилище компьютера и создаёт нужные настройки. Если ключ уже сохранён, его можно использовать повторно. Файлы конфигурации вручную заполнять не требуется. Соединение идёт напрямую в Tilda.

Текущие сборки не подписаны сертификатом издателя. macOS или Windows могут запросить подтверждение запуска. Сборка Mac с Apple Silicon проверена локально: встроенный Node.js и модуль системного хранилища загружаются. Для Windows проверены состав архива и контрольная сумма; запуск на Windows требует отдельной проверки на устройстве. Сборки Mac Intel и Windows ARM пока отсутствуют в выпуске.

## Как хранится ключ

- Mac: Связка ключей; Windows: Credential Manager; Linux для исходного пакета: Secret Service.
- В конфигурации приложения записываются только пути запуска. Секрет хранится отдельно, в записи ru.avtomato.tilda-connect / default.
- Поле ввода скрыто. Мастер работает на 127.0.0.1, ограничивает источник запросов и защищает операции от поддельных запросов. Внешние скрипты, аналитика и сохранение ключа в браузере отсутствуют.
- Запросы идут только на https://tilda.ru/api/mcp/ с HTTPS-заголовком авторизации. HTTP-перенаправления отключены. Текущий ключ фильтруется из ответов и ошибок.
- Пользовательские ключи отсутствуют в исходниках, архивах, JSON/TOML, аргументах запуска и переменных окружения.

Локальному процессу и Tilda ключ нужен для авторизации. Программы с достаточными правами в профиле пользователя и администратор могут получить доступ к системному хранилищу или памяти процесса. Содержимое запрошенных объектов Tilda передаётся выбранному AI-клиенту.

## Для распространения

Готовые системные пакеты находятся в dist/. Рядом сохраняются контрольные суммы SHA256. Передавайте системный пакет; получатель подключит свой собственный ключ.

Архив с суффиксом source.zip содержит исходники для разработчиков. В репозитории также есть каталоги плагинов для Codex и Claude Code. GitHub подходит для исходников и выпусков, а страница на сайте — для кнопок скачивания и короткой инструкции.

## Для разработчиков

Требуется Node.js 22+; сборка системных пакетов использует также Python 3, npm и curl. Обычным пользователям устанавливать эти компоненты не требуется.

```sh
npm ci --ignore-scripts --prefix plugins/tilda-connect
npm test
node plugins/tilda-connect/scripts/wizard.mjs
python3 scripts/build-desktop.py mac-arm64 windows-x64
npm run pack
```

Сборщик включает официальный Node.js 24.22.1 с закреплённой SHA256, зависимости из package-lock.json и платформенный модуль системного хранилища. На компьютере пользователя пакетный менеджер не запускается. Runtime копируется в профиль, поэтому скачанный архив после установки можно удалить. Все существующие настройки сохраняются; конфликтующее чужое подключение автоматически не заменяется.

При наличии ранее установленного Tilda Connect для Codex мастер использует его. Для новой установки создаётся локальное MCP-подключение в конфигурации Codex; для Claude — в соответствующем JSON-файле. После сохранения требуется перезапуск AI-приложения. Проверка ключа вызывает только MCP initialize и tools/list, без изменения проектов.

Технические команды исходного пакета сохранены:

```sh
node setup.mjs --client codex
node tilda.mjs key set
node tilda.mjs key status
node tilda.mjs check
node tilda.mjs key delete
```

При удалении локального ключа завершите работающие процессы. Для отзыва доступа удалите ключ также в профиле Tilda. Облачные версии клиентов в браузере этой локальной схемой не поддерживаются.
